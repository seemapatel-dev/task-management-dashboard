# Security Policy

## Supported versions

Security fixes are currently made against the latest version on the default branch.

## Reporting a vulnerability

Please do not report exploitable security issues in public GitHub issues.

If GitHub private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option on the repository's Security tab. Otherwise, contact the repository maintainer privately through the contact method listed on the maintainer's GitHub profile.

Include the affected component, impact, reproduction steps that do not access other people's data, and any suggested mitigation. Do not include real user data, passwords, API keys, or live access tokens.

Please allow the maintainer reasonable time to investigate and prepare a fix before publicly disclosing a vulnerability.
